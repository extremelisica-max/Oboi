# Роли и ответственность (обновлённые для цифрового прототипа)

Ниже перечислены роли и их ответственности, адаптированные под текущий проект — разработку и визуальную доводку прототипа веб‑приложения предпросмотра обоев/паттернов.

## 1. Владелец продукта / заказчик
### Ответственность
- определяет цель прототипа, приоритеты фич (splash, login, pixel‑perfect gallery)
- утверждает визуальные референсы и критерии совпадения (например 1440×900)
- принимает готовую версию и даёт фидбек для итераций

### Результат
Принятые критерии успеха и приоритеты фич, по которым команда ориентируется при разработке.

## 2. UI/UX дизайнер
### Ответственность
- готовит макеты и референсы (1440×900), задаёт типографику и отступы
- готовит ассеты (иконки, логотипы, превью изображений) и их экспорт для `public/assets`
- проверяет визуальное совпадение (spacing, размеры карточек, оттенки)

### Результат
Набор экспортированных ассетов и спецификация стилей для точного вёрстки.

## 3. Frontend-разработчик (React/Vite)
### Ответственность
- реализует SPA на React + Vite, включая `Splash`, `Login`, `Header`, `Gallery`, `Card`, `Modal`
- обеспечивает поведение: masonry, lazy load, сохранение/фавориты, IntersectionObserver
- устраняет ошибки сборки, добавляет `ErrorBoundary` и dev-overlay для отладки
- настраивает адаптивность: поведение при ширинах <1440 и >1440

### Результат
Рабочий прототип, запускающийся командой `npm run dev`, соответствующий дизайн‑спецификациям.

## 4. Инженер по качеству (QA)
### Ответственность
- проверяет соответствие скриншоту при разрешении 1440×900 (pixel‑check)
- тестирует поведение login (камера/капча), переходы, модальное окно и сохранение состояний
- проверяет загрузку ассетов и отсутствие CLS/лохапс

### Результат
Список багов и визуальных расхождений для исправления разработчиком.

## 5. Менеджер ассетов / контент‑менеджер
### Ответственность
- собирает реальные превью изображения и кладёт их в `public/assets/`
- проверяет форматы и размеры, заменяет повреждённые файлы
- поддерживает `src/data/sample.js` в актуальном виде

### Результат
Качественные изображения в `public/assets` и корректный тестовый датасет.

## 6. Медицинский эксперт (при необходимости)
### Ответственность
- консультирует по требованиям безопасности при печати/нанесении (если проект выходит за цифровой прототип)

### Результат
Рекомендации по сохранению медицинной функции и соответствию материалам (если применимо).

## Итог
Роли скорректированы под текущую работу: дизайн и фронтенд‑реализация цифрового прототипа. Если нужно, могу дополнить шаблоны описаний для Jira/тикетов под каждую роль.
