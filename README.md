# Обои-скины для ортезов (ортопедическая клиника)

Проект по созданию бесшовных декоративных паттернов для ортезов и других медицинских изделий. Цель — сделать ношение ортеза менее травмирующим визуально, при этом сохранив аккуратный, профессиональный и безопасный внешний вид.

## Что внутри

- `01_Широкоформатные_обои_ортопедическая_клиника_бриф.md` — исходный бриф проекта
- `02_Широкоформатные_обои_ортопедическая_клиника_роли.md` — роли и зоны ответственности
- `03_Широкоформатные_обои_ортопедическая_клиника_скиллы.md` — требования и навыки
- `04_Широкоформатные_обои_ортопедическая_клиника_инструкции.md` — рабочие инструкции
- `05_design_philosophy_measured_motion.md` — дизайн-философия и визуальная логика проекта

Каждая папка содержит варианты паттернов и превью для печати, адаптированные под масштаб ортеза.

## Ключевые принципы

- бесшовный повтор
- отсутствие текста и крупного центрального объекта
- узнаваемость даже на маленьком фрагменте
- безопасная печать и материал для контакта с телом
- проверка на авторские права перед использованием в продукте

## Рекомендуемый рабочий процесс

1. Проверить тему по целевой аудитории
2. Убедиться в бесшовности и корректном масштабе
3. Проверить авторские права и оригинальность
4. Подготовить print-ready файл и превью
5. Проверить результат на реальном изделии до релиза

## Статус

Проект находится в активной сборке ассортимента и подготовке готовых паттернов для печати.
