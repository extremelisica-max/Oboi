# Инструкция по выполнению проекта (добавлены шаги для цифровой реализации прототипа)

## 1. Подготовительный этап
- определить цель прототипа: точная вёрстка (1440×900), интерактивность (splash → login → gallery), критерии приёма
- собрать референсы и экспортировать ассеты в `public/assets/` (логотип, превью, иконки)
- назначить роли: дизайнер, фронтенд, QA, менеджер ассетов

## 2. Подбор или разработка паттерна

## 2. Подбор или разработка паттерна / подготовка превью для веба
- выбрать/создать бесшовный узор при необходимости и подготовить веб‑превью
- оптимизировать изображения: ресайз, webp/avif при возможности, добавить низкополигональный placeholder или blur-up
- проверить масштаб на реальном превью, а также в карточке галереи (min/max высота, reserved space)


## 2.1 Если в исходном паттерне элементы обрезаны или перекрыты

## 2.1 Работа с исходниками, если элементы обрезаны
Оставляем прежние шаги для печати — для веба важно: получить корректный чистый тайл и финальное превью без обрезанных элементов. Если исходник проблемный, сделать корректировку в графическом редакторе и экспортировать чистый тайл.

- частично скрыты другим элементом того же паттерна (перекрытие по z-order в исходной иллюстрации).

## 3. Подготовка макета для веб‑прототипа
- сверстать макет в React/Vite, вынести переменные стилей в `src/styles.css`
- обеспечить фиксированный результат для 1440×900 (точные отступы, размеры шрифтов и карточек)
- добавить механизмы загрузки: lazy loading, reserved heights, placeholder, fallback images

1. Рендерим EPS в PNG высокого разрешения (density ~400-500) для точного выделения элементов.

## 4. Разработка и отладка
- настроить dev‑сервер (`npm run dev`) и `ErrorBoundary`/overlay для быстрого обнаружения ошибок
- убедиться, что сборка не падает (исправить JSX/синтаксис)
- реализовать поведение: masonry колонки, reflow при ширине <1440, масштаб/увеличение карточек при >1440

5. Следим, чтобы ни одна иконка не пересекала край тайла и не перекрывала другую - так тайл гарантированно бесшовный и без "обрубленных" элементов.

## 5. Проверка качества (QA)
- выполнять pixel‑check на 1440×900 и фиксировать расхождения
- тестировать поведение login (имитация камеры, капча fallback), переходы и модалку
- проверять производительность и CLS

8. Масштаб иллюстраций регулируется по запросу клиента в процентах (например, "ещё на 15% меньше") - коэффициент применяется одновременно к размеру каждой иконки и к размеру тайла, чтобы пропорции и раскладка не менялись, только общий масштаб.

## 6. Развёртывание и сбор обратной связи
- собрать сборку для прод/preview, загрузить на временный хост и отправить ссылку заказчику
- собрать отзывы и вносить правки итеративно



## Главные правила для цифровой части
- всегда держать side padding 24px и внутренние паддинги карточек 16px, spacing между search и chips 20px
- заменить inline‑SVG на ассеты из `public/assets` для предсказуемого рендера
- обеспечить reserved height для изображений, чтобы не было CLS



## Результат
Рабочий цифровой прототип, соответствующий визуальным критериям (1440×900) и интерактивным требованиям. Документ включает и печатную часть процесса, и шаги для веб‑реализации.

- проверить цветопередачу тиража относительно превью
- соблюдать направление и совмещение узора, если изделие состоит из нескольких деталей

## 6. Вырезка по контуру
- аккуратно вырезать по форме готового ортеза
- освободить вентиляционные отверстия, застёжки и подвижные элементы — узор не должен их перекрывать

## 7. Проверка качества
- ровные края без отслоений плёнки
- узор на готовом изделии выглядит аккуратно, без «обрубленных» крупных элементов
- материал соответствует требованиям безопасности (гипоаллергенность, отсутствие раздражения кожи)
- все функциональные элементы ортеза работают как прежде

## 8. Финализация
- утвердить готовое изделие у медицинского консультанта
- занести паттерн в общий каталог (с превью и print-ready файлом) для повторного использования

## Главные правила процесса
- узор всегда бесшовный и без текста
- масштаб паттерна проверяется на размере реального изделия, а не только на большом превью
- любой новый персонаж/образ сначала проверяется на авторские права
- декоративное покрытие никогда не должно мешать медицинской функции ортеза

## Результат этапа
Готовое изделие с аккуратно наклеенным и вырезанным узором, безопасное для пациента и полностью сохранившее функциональность ортеза.
